# 甜甜练习

每答对一题，演出和音乐就不断升级的计算练习。只需浏览器即可运行。

吉祥物「甜甜」会把你输入的数字搬运到位，答对了就为你庆祝。随着题目推进，画面和声音会越来越热闹，最后变成祭典一般的盛况。答错也不会掉气势，没有游戏结束。

## 特点

- 覆盖小学 1～6 年级的 58 个计算技能（依日本学习指导要领设计）：加减乘除、竖式分步输入、小数、分数、百分数等
- 「我的等级」模式：从实力测试开始，根据熟练度逐步解锁下一个技能
- 学年模式、练习、复习、技能树界面
- 全部答对得 100 分。首次答对率达到 80% 以上，就能进入限时附加挑战，冲击超过 100 分的得分
- 音乐和音效全部由 Web Audio API 实时合成（不使用任何音频文件）
- 支持手机竖屏和 PC。PC 上可用数字键和 Backspace 输入
- 设置中可调节动效强度，也可静音
- 所有记录都保存在本机（localStorage）内，不会上传到任何外部服务器

## 本地运行

无需构建，直接静态托管 `app/` 目录即可。

```bash
python3 -m http.server 8000 -d app
```

用浏览器打开 `http://localhost:8000/`。游戏使用 ES Modules，直接用 `file://` 打开无法运行。

## 测试

需要 Node.js 20 及以上。

```bash
node --test tests/*.test.mjs
```
