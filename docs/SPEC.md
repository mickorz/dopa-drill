# 多巴练习 — 公开版规格书

多巴练习是一款每答对计算题就让吉祥物的动作、画面演出与音乐不断增强的浏览器游戏。本书面向玩家与家长，以及有意开发、修改本作的人，说明当前实现的运行方式。数值可能随今后的调整而变更。

## 1. 概要与设计思路

本作旨在提供一种每天坚持少量计算、并能确认自己相对过去有所成长的体验。基础题目在超时后仍可继续，全部答完即得 100 分。没有游戏结束。

误答会显示为"可惜"，可以重新作答。已获得的星星、奖杯、演出不会因失败或缺席而被收回。连续记录有补足休息日的机制，成长对比只显示有改善的项目。奖励通过达成条件解锁，不存在抽选或付费获取。

界面为简体中文，同时面向小学生的计算练习与成人使用。以智能手机竖屏为主，也支持 PC 的鼠标与键盘操作。无需注册账号。记录按浏览器分别保存，因此不会与其他设备自动同步。

## 2. 界面与流程

### 2.1 界面一览

| 界面 | 内容与主要操作 |
| --- | --- |
| 标题界面 | Logo、多巴吉、"我的等级"、其正下方的"复习"、1~6 年级、技能树、奖杯、收藏、任务、打卡日历、设置、"？"（玩法说明） |
| 答题界面 | 题目、答题格、专用数字键盘、答对数、可惜次数、计时、多巴、连击、进度显示、静音 |
| 基础结果 | 100 分、用时、首次答对率、多巴，成长／技能／任务的结果。达成条件时的附加挑战入口、重做答错的题、再来一次、结束（返回标题） |
| 最终结果 | 含附加挑战的得分与多巴、答对数、可惜次数、任务，重做答错的题与返回标题的操作 |
| 技能树 | 前置关系、解锁／练习中／大师的状态、星星、生锈标记、技能的说明与练习、记录的部分删除 |
| 奖杯 | 按分类・系列展示的成就、获得日期、条件与奖励、筛选、即将达成的成就 |
| 收藏 | 试用／试听已解锁的演出，每个类别可固定选择或选择"随机" |
| 设置 | 题目数量、声音、音量、动效强度、演示模式、全部重置 |

通常按"标题界面 → 基础题目 → 基础结果 → 可选的附加挑战 → 最终结果"推进。复习只进行到基础结果为止。结果界面的操作按钮固定在底端，即使成长记录增多也能继续下一步操作。

### 2.2 首次引导与"？"帮助

首次使用时显示 5 页引导，依次为：怎么玩、我的等级、一年级～六年级、技能树、推荐使用"我的等级"。设置按钮下方的"？"（玩法说明）可以重新显示加入奖杯与收藏后的 7 页说明。

引导用聚光灯照亮说明对象，必要时进行滚动。说明文字显示在独立的卡片上，多巴吉通过移动、指点和表情来引导，不以台词形式显示。最后一页指向"我的等级"与"？"，若无法同时收入画面，则在卡片内显示相同的问号图标。

通过"上一页""下一页""跳过"以及最后的"开始！"进行操作。Enter、右方向键前进，左方向键后退，Escape 跳过，Tab 在引导内移动焦点。点击暗幕不会关闭，引导期间无法操作背景中的按钮。

无论看到最后还是中途跳过，都保存为已显示。首次引导结束后，按免错锤、登录奖励、奖杯通知的顺序处理。全部重置后会再次显示首次引导。演示中以及部分确认用 URL 下不会自动显示。

## 3. 模式

### 3.1 我的等级

首次进入为"实力测试"。沿着按年级、前置关系深度排列的技能前进，若首次答对，则把出题对象及其前置技能一并设为大师・☆1。移动步长最初为 6，答对后取当前步长的 1.3 倍向上取整、上限 12，误答后减半向下取整、下限 1。误答后回到比最后一次首次答对的位置更靠前的范围。基础题目做完即视为测试完成。

此后的出题基于前置关系深度、年级、技能定义顺序来选择。从已大师技能的最后 6 个中选取复习，复习名额为 `min(候选数, max(1, round(题数 × 0.3)))` 题。优先选择已生锈的技能，其余从候选中随机选取。若没有已大师的技能，则复习名额为 0。

剩余部分按顺序反复使用已解锁・未大师技能的开头 4 个。若全部已大师，则从全部已大师技能中选择。附加挑战反复使用未大师候选的最后 3 个技能，若没有则使用已大师技能的最后 3 个。测试刚完成后的附加挑战从已解锁・未大师的开头选取。

### 3.2 年级模式

无论解锁状态如何，都从所选年级的技能出基础题目。按前置关系由浅到深的顺序排列，并附加随机扰动。解答结果也会反映到通常的熟练度中。

附加挑战的前 6 题反复使用该年级技能序列第 `floor(技能数 × 0.55)` 个及之后的技能。第 7 题起切换到下一年级开头的最多 4 个技能。6 年级则继续同一年级的后半部分。

### 3.3 练习

从技能树中选择已解锁的技能进行练习。已大师的技能可以从说明界面开始练习。基础题目使用该技能本身，附加挑战从以该技能为直接前置且已解锁的技能中选取。若无对象则继续同一技能。

年级模式与练习中，满足条件的时间胶囊可能替换基础题目中的 1 题。这一题可能超出指定的年级・技能范围。

### 3.4 复习

在解完包含误答的题目时，把题目本身最多保存 40 题。以题目标题和算式作为标识符去除重复。中途中断的未完成题目不会追加。

可以从标题界面与结果界面的"重做答错的题"按钮开始。从已保存列表的末尾选取，上限为所设题数与 10 中的较小者。即使从结果界面的按钮开始，也不限于该次的误答，而是使用此前遗留的列表。

首次答对而重做正确的题目会从列表中删除，再次误答的题目保留。全部答完即得 100 分，没有附加挑战。也会反映到通常的成长记录、熟练度与任务中。

### 3.5 演示模式

通过设置中的"观看自动演示"开始自动操作。把从全部技能中选出的问题按由易到难排列，附加挑战从 4 年级以上的技能中选取。使用通常的输入、判定与演出，也会包含误答。基础部分误答题数的上限为 `floor(题数 × 0.2)`。

基础、附加挑战、最终结果循环一周后返回标题界面，并解除演示。点击或按键操作也可以结束。开始后紧接着的点击有 600ms 的忽略时间。演示的游玩结果不计入历史、熟练度、复习与成长统计，也不推进任务与奖杯的获得。返回标题界面后照常进行通常的登录处理。

固定的演出在演示中照常使用，"随机"的类别只从已解锁中选择。URL 的 `?demo` 是与该自动操作不同的另一个功能。

## 4. 单次游玩与输入

### 4.1 基础题目与附加挑战

题目数量为 6、10、14 题，初始值为 10 题。基础的目标时间为 `ceil(题数 × 18 ÷ 10) × 10` 秒，6 题为 110 秒，10 题为 180 秒，14 题为 260 秒。超时仍可继续，不扣分。基础的经过时间从游玩开始到跑完全程，包含题目切换。

"答对"指完成到最后一位的题目数，"可惜"指接受的数字相对当前答题格错误的次数。"首次答对"指包括中途输入在内一次都没有误答而完成的题目。基础的首次答对数除以题数的比例不低于 0.8 时，可以选择附加挑战。

附加挑战默认 90 秒。以开始处理的时刻加上 90,000ms 与导入用 900ms 设定截止时间。这不是从最初可输入时刻保证 90 秒的方式，题目切换期间计时照常推进。确认对话框期间暂停。时间到即确定得分，进入最终结果。未完成题目没有得分，但已接受的正解格带来的多巴保留。

### 4.2 数字的输入

用专用数字键盘和 PC 的数字键逐位输入，并当场判定。没有回答确认按钮。正确的数位会被保留，错误的数字由下一次输入替换。Backspace 是删除当前错误数字的操作，不会撤销已答对的数位。

在智能手机上，会根据包含浏览器操作栏在内的显示区域调整题目留白与数字键盘的高度。包含 0 与删除键的最下一排放在底端安全区域之上，画面尺寸变化时也会重新计算题目文字的大小。

| 题目形式 | 输入顺序与自动显示 |
| --- | --- |
| 横式 | 从答案最左边的数位开始输入 |
| 横式带余数除法 | 先商，后余数 |
| 加减法竖式 | 从最低位开始。进位、退位的辅助数字自动显示 |
| 乘法竖式 | 从低位开始输入部分积，有多个部分积时总和也从低位开始输入 |
| 除法竖式 | 依次为商的高位、减后的余数、下一位商。积、落下的数字、最后的余数 0 自动显示 |
| 小数 | 小数点自动显示，只输入数字 |
| 分数 | 先分母后分子。带分数依次为整数部分、分母、分子 |
| 比・含字母式・近似数・百分数 | 从指定空格的左侧数位开始输入 |

分数按预先准备好的回答形式判定。3 年级的同分母分数保留原分母，接受未约分的答案。其他分数计算使用生成时确定的最简分数・带分数形式。不是自由输入等价的其他表示再行判定的方式。

### 4.3 误答与提示

错误的数字使用紫色虚线框。同一格误答 2 次后，若应参照的数字有定义，则进行高亮・指点。第 3 次起显示计算的中间算式或乘法口诀行等提示。提示中可能包含相当于答案的数值。

误答会使连击归零，但不扣得分与多巴，并维持演出阶段与 BGM。为突出误答音会暂时压低 BGM，配以弹跳的音效和多巴吉重新振作的表演。

## 5. 得分・多巴・连击

### 5.1 得分

基础跑完全程即 100 分。设附加挑战完成的题目数（从 0 计）为 `k`，该题的加分为 `10 + 5 × k` 分。完成 `n` 题附加挑战的总得分为下式。

```text
100 + 10 × n + 5 × n × (n − 1) ÷ 2
```

5 题为 200 分，10 题为 425 分，15 题为 775 分，23 题为 1595 分，30 题为 2575 分。得分没有固定上限。没有按连击、答题速度、可惜次数进行的得分倍率或扣分。

### 5.2 多巴的计算

多巴是演出用的数值，与得分不同。内部值 `L` 以常用对数保存，显示值基于 `10^L`。游玩开始时 `L = 0`。

设基础的基准曲线为 `B(f) = 2.3 × clamp(f, 0, 1)^1.15`，附加挑战的基准曲线为 `X(n) = 2.3 + 3.0 × (1 − exp(−n / 10))`。

设基础的总题数为 `N`、已完成题目数（从 0 计）为 `q`、当前题目的答题格数为 `m`、本次答对的格（从 1 计）为 `s`，则该次输入的基准增量为 `B((q + s/m)/N) − B((q + (s−1)/m)/N)`。设附加挑战的已完成题目数为 `k`，则每格的基准增量为 `(X(k+1) − X(k))/m`。

答对时先将连击数 `c` 加 1，再按下一式反映该次输入。

```text
倍率 M(c) = 1 + (2 − 1) × min(1, max(0, c) / 20)
新的 L = min(9.08, L + max(0.003, 基准增量) × M(c))
```

10 连击为 1.5 倍，20 连击以上为 2 倍。上限为对数值 9.08，按原显示值即精确的 `10^9.08`。由于增量有 0.003 的最低值，实际到达值不能仅由基准曲线的终点决定。第一次答对也是 1 连击・1.05 倍，附加挑战开始时连击归零并继承多巴。

显示时不足 1 万取整显示，之后附加"万""亿"等单位。单位内的数值不足 10 时显示到小数第 1 位，10 以上则舍去取整显示。达到 100、1000、1 万、10 万、100 万、1000 万、1 亿时有里程碑演出。通常游玩的上限不会达到兆以上。

### 5.3 连击的时间与显示

每答对一格加 1 连击，并跨题目延续。2 连击以上显示，20 连击以上显示"多巴×2 MAX"。误答或时间到则归零。不过，当前实现中 1 连击的状态不在超时判定对象之内。

年级 `g` 的普通格时间为 `3000 + 600 × (g − 1)` ms，每题的第一格额外加 2500ms。年级限制在 1~6，不明时按 3 处理。

| 年级 | 普通格 | 每题第一格 |
| --- | --- | --- |
| 1 | 3000ms | 5500ms |
| 2 | 3600ms | 6100ms |
| 3 | 4200ms | 6700ms |
| 4 | 4800ms | 7300ms |
| 5 | 5400ms | 7900ms |
| 6 | 6000ms | 8500ms |

在接受输入的时刻设定期限，题目切换与确认对话框期间不消耗。剩余时间条低于 30% 时高亮。10、20、30、50、75 连击以及 100 以上每 50 连击进行大幅庆祝。5 连击以上中断时，短暂显示结束时的数量。

## 6. 出题范围与技能树

### 6.1 范围与生成

计算被划分为 58 个技能。按年级分：1 年 8 个、2 年 13 个、3 年 14 个、4 年 10 个、5 年 8 个、6 年 5 个。赛道为"加减法""乘除法""小数与分数""其他"4 条。全部技能的名称、标识符、前置与生成条件汇总于 `docs/curriculum.md`。

对象为四则计算、伴随中途输入的竖式、小数、分数、近似数、因数与倍数、运算顺序、百分数、相等的比、字母的值。不出现图形、测量、图表、应用题、汉字数字输入。

每次根据技能条件用随机数生成。利用最近 24 题的签名与该次游玩内已出题的签名避免重复。候选生成有重试上限，因此在候选较少的技能等情况下可能出现重复。时间胶囊与复习是为重现相同题目的例外。

### 6.2 显示与解锁

4 个赛道各分 2 列、共 8 列显示，窄屏时可纵横滚动。优先按年级顺序排列，5、6 年级放在 1~4 年级之下。前置关系的连线会绕开其他节点迂回，仅仅排在同一列并不表示依赖关系。

没有前置的技能从一开始就解锁，有多个前置时必须全部大师。状态区分"未解锁""新技能（NEW）""练习中""大师"。通常的大师条件是至少有 6 题记录，且最近 6 题中 5 题以上首次答对。一旦大师的技能即使误答也不会退回。实力测试的批量授予是该次数条件的例外。

### 6.3 技能的星星

大师后依次获得 ☆1~☆5。必须逐级满足条件，若条件齐备，同一次判定可以连升多级。总计上限为 290。

速度的判定使用每题解答时间除以基准时间的比率。基准时间为 `第一格的连击时间 + max(0, 答题格数 − 1) × 普通格的连击时间`。只从该技能首次答对的题目求比率的中位数。

| 星星 | 条件 |
| --- | --- |
| ☆1 | 已大师 |
| ☆2 | 最近 20 题齐全，首次答对率 0.9 以上 |
| ☆3 | 最近 10 题齐全，其中 5 题以上首次答对，时间比率的中位数不超过 1 |
| ☆4 | 最近 3 题全部首次答对，且各题日期在获得 ☆3 之日 7 天以后 |
| ☆5 | 最近 20 题齐全，首次答对率 0.95 以上，时间比率的中位数不超过 0.6 |

☆4 的 3 题不限于同一天。星星不会因通常的游玩或休息减少，在技能记录删除与全部重置时消失。说明界面显示下一颗星的条件、当前值、已解题数与最快解答时间。

### 6.4 生锈

把已大师且距最后一次首次答对超过 `21 × 86400000` ms 的技能作为候选，按最旧顺序最多对 3 个显示"锈"标记。若无首次答对时间，则依次参考实力测试的授予时间、大师时间。

生锈的技能首次答对 1 题即被打磨，保留星星并移除标记。因打磨，其他较旧的技能可能成为新的显示对象。用于"我的等级"的复习以及打磨任务。

### 6.5 技能记录的删除

对有记录的技能长按 600ms，或聚焦后按 Delete，会打开确认。从按下位置移动超过 10px 时中止长按操作。

确认后，删除该技能以及直接・间接依赖它的技能的记录与星星。所选技能在前置仍满足时回到新技能（NEW），前置不满足则回到未解锁。历史、复习、累计统计、奖杯、收藏、实力测试已完成的状态予以保留。

## 7. 坚持机制

### 7.1 历史・打卡日历・登录奖励

在基础结果保存历史，附加挑战结束后更新同一历史的得分、追加答对数、可惜与多巴。最多保存 3000 条。打卡日历显示每天的最高分与游玩次数，可从日期打开详情。可以浏览过去的月份，不能进入未来的月份。

连续天数以今天为起点，今天还没玩则以昨天为起点。同时显示最长纪录与签到贴纸的数量。游玩日与登录日是分开的，仅打开标题界面不算游玩日。

登录奖励按设备日期每天 1 次。以星星、爱心、花朵、音符、三叶草、小花勾、王冠 7 天为周期领取贴纸。中间夹入未被免错的缺席日时，周期从头数起。贴纸在打开显示的时刻即视为领取，关闭或重新加载都不会在同一天重复领取。

### 7.2 免错锤

用 1 把可以把没玩的一天变为"免错"，接续游玩与登录的连续记录。不会把该天计入游玩天数，也不会补发休息日的贴纸。初始持有 1 把，持有上限 3 把。

当最后游玩日在最近 7 天之内、所持数量足以补满昨天为止的空缺日、且能保住 2 天以上的连续时，标题界面每天提议使用 1 次。被拒绝的当天不再提议。使用后在打卡日历上盖"免错"章。使用记录最多 50 条。

### 7.3 每日任务

根据设备日期与当天选取时点的记录，确定 2 个简单任务与 1 个费时任务并保存。同一天即使更改设置也不会重选。日期变更后的更新处理切换到新列表。候选为固定的 11 种，加上 1 种视生锈情况而定的任务。

| 框位 | 候选与达成条件 |
| --- | --- |
| 简单 | 玩 1 局、打出 5 连击、首次答对 5 题、复习 1 题、做 1 题 NEW 技能 |
| 费时 | 进入附加挑战、在附加挑战答对 5 题、打出 20 连击、玩 2 局、按年级玩 1 局、练习中的技能做 10 题、指定技能首次答对 3 题 |

没有复习・NEW 的对象时，去掉相应候选。附加挑战相关以最近 5 条历史中有附加挑战记录为条件，20 连击以 `题数 × 平均答题格数 >= 26` 为条件，练习中 10 题以已完成实力测试且存在未大师候选为条件。同一天不会叠加衡量相同指标的任务。

所需时间的筛选模型将 1 局计为 `(题数 × 18 + 预计有附加挑战时 90 + 30) / 60` 分钟。首次答对 5 预计 `ceil(5 / (题数 × 0.7))` 局，练习中 10 题预计 `ceil(10 / (题数 × 0.6))` 局，20 连击预计 2 局。复习按最多 10 题计算，把各模式可以共同完成的项叠加，选择总计 15 分钟以内的组合。这只是估算，并不限制实际所需时间。

打磨候选在有"锈"的日子、由日期决定的随机数小于 0.5、且最近 7 天内提示次数不足 2 次时进入选择范围。可以从标题界面直接开始对象技能的练习，达成需要在同一技能首次答对 3 题。与消除"锈"本身所需的 1 题条件不同。

进度在游玩中累计，达成时在画面顶端通知。复习也计入共通的通关、首次答对、连击条件。3 个任务全部达成后，当天可获得 1 把锤子并在日历上做标记。若已达持有上限则只播放演出，奖励不延后补发。

### 7.5 与上一次比较

在基础结果中，把比同一技能以往记录有提升的项目以"进步啦！"显示，最多 3 行。本次与比较对象双方都需要 3 题以上。比较对象为：上次游玩的日子、21 天前以前最近的一天、最初解题的 3 题。不把同一天内的过去回合作为比较对象。

解答时间按每答题格的平均值比较，显示为换算成本次平均格数的每题秒数。时间缩短 10% 以上，或首次答对率改善 10 个百分点以上的项目成为候选。每个技能选取最大的改善 1 项，整体按改善幅度从大到小显示。没有改善就不显示。实力测试、演示模式、停止成长记录的确认用 URL 不在此列。

### 7.6 时间胶囊

从每个技能保存的最初 3 题中，选择已大师、距解题时超过 `30 × 86400000` ms 且未使用的问题中最旧的一个。

通常的"我的等级"、年级、练习的基础题组不少于 4 题时，替换从 0 计的第 `max(1, min(N−2, floor(N/2)))` 个。实力测试、复习、附加挑战、演示、停止成长记录的确认用 URL 不在此列。每天最多 1 题，保存预告结束时刻的日期，因此此后即使中断也不会在同一天再次提示。题目完成时即视为已使用。

通过信封预告与橙色边框表明是过去的题目。比较时，本次时间小于过去的 0.95 倍算作时间缩短，否则看误答次数是否减少，两者皆无则显示再次解出与日期。恰好缩短 5% 不显示为时间缩短。

## 8. 多巴吉与演出・声音

多巴吉原则上不使用语言，以肢体表达。造型基准为 `docs/dopakichi.svg`（V5，配方见 `docs/dopakichi-recipe.md`）。当前形象是白色布偶小猫「甜甜」：毛绒锯齿轮廓的圆脸（端正对称）、三角猫耳（灰色重点色 + 耳内粉 + clipPath 毛束）、蓝色玻璃感大眼（4 站虹膜渐变 + 双层瞳孔 + 高光）、胡须、分层胸毛、短胖身体、蓬松灰尾、胸前粉色蝴蝶结与金色铃铛。基本色为布偶白渐变 `#FFFEFD→#FFF7F4`、耳/额/尾重点色 `#D9CECF→#B9AAAC`、耳内粉 `#FFB7C6`、虹膜蓝 `#C9E4FF→#244E91`、蝴蝶结粉 `#FFC4D4→#ED8EAB`、铃铛金 `#FFF7BD→#D79A35`、腮红 `#FFC7D3`、轮廓暖棕 `#744947`（三级粗细 6 / 4.2 / 3.1）。

输入的数字用空着的手搬运。左右手可以分别搬运不同的数字，判定与搬运分开处理，不会让下一次输入等待。中途答对・最终答对使用跳跃、拍手、旋转等，误答时先瘫倒再重新振作。误答表演有 10 种，前期使用 4 种，中期使用 8 种，强度 0.6 以上时从 10 种中避开与上一次相同的来选择。

设基础的问题编号（从 0 计）为 `i`、题数为 `N`，演出强度为 `E = 0.08 + 0.92 × (i/(N−1))^1.3`。只有 1 题时取 `E = 1`。附加挑战按完成数 `k` 取 `tier = floor(k/3)`、`E = 1 + min(0.5, tier × 0.1)`。

随强度叠加背景、小花勾等答对标记、纸屑、星星、烟花、硬币、观众、行进、灯组、摇晃等。压轴演出从巨型多巴吉、烟花大会、火箭、大游行中选择，最后展示 100 分。保持输入与数字键盘的布局、竖式数位的对应不变。

音乐与音效用 Web Audio API 合成，不加载外部录音素材。共 5 首曲目：基础的马林巴进行曲，加上 8 比特、祭典乐曲、铜管乐队、电子乐。使用振荡器、噪声、滤波器与残响等，逐段叠加打击乐、低音、和声、旋律。

基础的节拍为 `112 + min(1, E) × 16` BPM，通常最初为 113.28 BPM，最后为 128 BPM。最后一题在基准上升 2 个半音。附加挑战为 `134 + tier × 5` BPM，调在基准上升 `2 + min(tier, 5)` 个半音。变调设有上限，节拍速度除该式外没有固定上限。

按键、数字落位、答对、误答、多巴里程碑、计时等都有声音补充，音高与乐曲的和声同步。声音的启动依赖浏览器要求的用户操作。背景使用 WebGL，在不可用或上下文丢失时切换为 CSS 背景。

## 9. 设置与无障碍

| 设置 | 内容与初始值 |
| --- | --- |
| 题目数量 | 6、10、14 题。初始值 10 题 |
| 声音 | 开／关。初始值为开。也可通过答题界面的静音按钮更改 |
| 音量 | 0~100%。初始值 80% |
| 动效强度 | 0~100%。未设置时，若设备指定减少动态则为 0%，否则为 100% |
| 演示模式 | 自动操作循环展示一周（"观看自动演示"按钮） |
| 全部重置 | 确认 2 次后初始化设备内的数据 |

动效强度影响粒子量、摇晃、闪光、背景、观众与多巴吉的大动作。0% 时停止主要的移动・摇晃・闪光，引导也改为静止姿势。但这不是停止全部绘制的功能，仍保留通常画面的呼吸等表现与少量粒子的处理。调整数值时可以在设置界面试用其反应。计算判定与得分规则不变。

Escape 会关闭打开中的对话框，或在非标题界面时打开"返回标题界面？"的确认。以"继续玩"为初始焦点，确认期间停止输入、基础的经过时间、附加挑战与连击的期限、每题的计时。到中断为止已完成题目的熟练度等仍会保留。若在基础结果之前，则不创建通关历史。演示中的 Escape 即结束演示。

提供按钮的无障碍名称、焦点显示、数字以外的标签、引导内的焦点循环。但并不保证仅靠读屏软件完成全部游玩，也不保证在所有设备上的可操作性。

高度 700px 以下时调整题目区、演出区域与留白，使数字键盘的最下一排也收入画面。短屏下仍保持按键高度 48px。

全部重置的第 1 次以"全部重置"显示将要删除的内容，第 2 次以"真的要删除吗？"确认不可恢复。两者都以"取消"为初始焦点。取消、Escape、点击背景都不会删除。第 2 次确认后，删除所有带 `dopa-drill` 前缀的保存键，废弃内存缓存并重新加载。无关的键予以保留。

设置、历史、熟练度、星星、成长记录、奖杯、收藏选择、贴纸、任务、道具、首次引导状态是初始化的对象。重启时会重新创建首次引导与初始道具等。即使浏览器拒绝删除，处理也不会异常终止，但不保证已保存数据被清除。

## 10. 保存与隐私

保存于浏览器的 localStorage，键为 `dopa-drill:v1`，数据版本为 1。没有输入姓名等个人信息的栏目，应用不会把学习记录发送到服务器。没有广告、外部统计、排行榜、设备间同步。从分发服务器获取游戏的静态文件运行。

当保存区域不可用、读取失败或 JSON 损坏时，以初始状态启动，即使保存失败也会继续当前的游戏。清除浏览器数据、保存限制、在其他浏览器或分发源使用时，记录无法迁移。

| 累计统计 | 完成题目・格・首次答对・误答，基础通关与模式，基础用时，最高多巴，附加挑战，最高连击，复习，游玩天数，打磨次数，比较・时间胶囊 |
| 坚持与奖励 | 贴纸、登录日、免错日、锤子、任务、已获得奖杯、演出选择 |

单题的解答时间从接受输入到最后一次答对输入为止，不含题目间的演出与确认对话框。累计的题目・格・误答在完成题目时才计入，因此中途结束的未完成题目的操作不进行统计。

对还没有统计的保存数据，会用历史中可得的值进行初始化。历史中无法得知的值（如过往格数、最高连击）从 0 开始计测。确认用 URL 并不是停止全部保存的功能。具体差异见下一章。

### 11.3 确认用 URL 参数

按 `/app/?count=6&seed=123` 的方式指定。

| 参数 | 行为 |
| --- | --- |
| `count=6`、`count=10`、`count=14` | 选择启动时的题目数量 |
| `seed=<数值>` | 固定选题・生成等使用的随机数。不固定全部视觉效果的随机数 |
| `extra=<秒>` | 替换附加挑战默认的 90 秒。开始时的 900ms 附加保持不变 |
| `skill=<技能ID>` | 把通常的选题替换为该技能。与复习、固定模板并用时存在选择处理的优先级 |
| `demo` | 从"我的等级"入口打开固定模板的基础题组。第 1 题为 27＋35。不进行自动操作 |
| `capture` | 收集声音事件的确认途径。抑制通常的实时声音输出以及自动引导・标题奖励通知等 |

使用 `skill` 与固定模板游玩时，停止通常的解答时间・成长统计・任务，但通关历史与复习仍会保存。`skill` 时若出题计划为实力测试，该计划侧的大师授予与测试完成的保存照常工作。奖杯判定在 `skill` 与 `capture` 下停止，仅指定 `demo` 不会停止。`capture` 下通常的进度・历史・统计的保存继续。请不要把它们当作不留记录的练习功能使用。
