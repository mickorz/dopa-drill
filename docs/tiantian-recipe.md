# 甜甜（Tiantian）布偶猫 SVG 拼装配方 · V5

> 源文件：`docs/tiantian.svg`（造型原典，纯矢量手写）
> V5 要点：clipPath 锁定耳内毛束、耳根盖片衔接、端正对称脸（无歪头）、右睫毛 = 左睫毛镜像、蓝眼玻璃质感、短胖身体、蓬松灰尾、粉结金铃

## 1. 全局设置

- **坐标系**：`viewBox="0 0 1024 1024"`，y 轴正方向朝下，**中轴 x=512**（鼻/铃铛/身体中心）
  - 角色占位：耳尖 y≈92，脚底 y≈936；地面阴影椭圆 `(515, 925) rx=348 ry=26`，`#bda6a4` opacity .18 + `feGaussianBlur stdDeviation=9`
- **描边系统**（全部圆角 cap/joint）：

| class | 颜色 | 粗细 | 用途 |
|---|---|---|---|
| `.outline` | `#744947`（暖棕） | 6 | 主轮廓 |
| `.mid` | `#744947` | 4.2 | 次级轮廓（眼白、耳内粉、鼻、下巴、铃铛） |
| `.softline` | `#b39a99` | 3.1 | 胡须、趾线（fill:none） |
| `.furline` | `#dfd2d0` | 2.5 | 毛流线（opacity .68，fill:none） |

- **渐变库**（`<defs>`）：

| id | 类型 | 色标 | 用在哪 |
|---|---|---|---|
| `fur` | linear 垂直 | `#fffefd` → `#fff7f4` | 头、身、耳外、胸毛、腿 |
| `furShade` | linear 对角 | `#f8eeee` → `#eadcda` | ⚠️ 已定义未使用（备用） |
| `point` | linear | `#d9cecf` → `#b9aaac` | 耳部重点色 |
| `tail` | linear 对角 3站 | `#eee5e4` → .55 `#d6c7c9` → `#b6a6a9` | 尾巴 |
| `iris` | radial (34%,28%,76%) 4站 | `#c9e4ff` → .38 `#78b5ff` → .72 `#4381da` → `#244e91` | 虹膜 |
| `bow` | linear | `#ffc4d4` → `#ed8eab` | 蝴蝶结两翼 |
| `bell` | radial (32%,22%) | `#fff7bd` → .45 `#ffd773` → `#d79a35` | 铃铛 |

- **滤镜**：`soft`（blur 9，地面阴影）、`eyeGlow`（blur 3.5，腮红柔化）
- **实色补丁**：纯白 `#fffdfb`（前爪），阴影层 `#f4e7e5 / #f4e8e6 / #f3e7e5 / #f5e9e7`

## 2. 图层顺序（从后到前）与关键参数

① 地面阴影 → ② 尾巴 → ③ 身体 → ④ 耳朵 → ⑤ 耳根盖片 → ⑥ 头 → ⑦ 脸 → ⑧ 胸毛 → ⑨ 蝴蝶结 → ⑩ 后腿 → ⑪ 前腿 → ⑫ 前爪 → ⑬ 趾线

### ④ 耳朵（V5 核心改进）
每只四层，**内层全部包在 clipPath 里**（clip 路径 = 耳外壳，毛束永不溢出）：
1. 外壳 `.outline` + `fur`（左耳 `M288 367 …`，耳尖 y=92）
2. 灰色重点色 `point`（clip 内）
3. 耳内粉 `#ffb7c6`（`.mid`）
4. 白色毛束 ×2（`#fffdfa` + `#fffaf8`）

### ⑤ 耳根盖片
两小片 `fur` 色（opacity .94，无描边）垫在耳根，遮住耳-头交界线。

### ⑥ 头
- 毛绒锯齿轮廓一条 path（~50 组凸凹 C 曲线对），x≈178~846，y≈196~755
- 额头灰色重点色（蝶形 `.78` + 内层 `.5`）
- 眉斑（`#eadfdd` .78）+ 两侧 4 组毛流 + 4 块侧影

### ⑦ 脸（端正对称，无歪头）
- **睫毛**：左睫毛手绘（外眼角 (326,442) 起）；**右睫毛 = 左睫毛 `translate(1024 0) scale(-1 1)` 镜像**，画在眼白后面
- **眼睛**（镜像对，中心 (402,503)/(622,503)，`rx=72 ry=82`）：
  1. 眼白 `.mid`
  2. 虹膜 `iris` 4 站渐变（中心向右上偏 3~6px）
  3. 瞳孔 `#244a83` + 内层 `#163663` .62（双层加深）
  4. 大高光 r=19 + 小高光 r=9.5
  5. 底部反光：椭圆 `#95c8ff` .46 + 两个圆 `#bce0ff` .72
- **腮红**：椭圆 `rx=47 ry=24` `#ffc7d3` .52 + `eyeGlow` 柔化 + 三根斜线 `#f2a9b8`
- **鼻嘴**：鼻 (512,553~571) `#f6a1b2` → 嘴角弧 → 下巴盾 `#f298ad` → 高光 `#ffc2cf` .78
- **胡须**：每边三根 `.softline`，同高对称

### ⑧~⑨ 胸毛 + 蝴蝶结
- 胸毛组 `translate(0 22)`，锯齿云朵形，底部 y≈835
- 结组 `translate(0 10)`：两翼 `bow` 渐变 + 飘带 `#f29ab5` + 翼影 `#d96b8e` + 铃铛 r=41（口弧 `#d09131` / 铃孔 `#5a4040`）

### ⑩~⑬ 下半身
- **后腿**画在胸毛/结**之后** = 大腿压住胸毛两侧（遮挡关系正确）
- 前腿（短）→ 前爪（`#fffdfb`）→ 趾线 `.softline` opacity .55

## 3. V5 核心技巧

1. **clipPath 锁形**：耳内所有细节包在「外壳同形 clip」里，随便加毛束不会画出耳外
2. **镜像三件套**：a) 显式镜像坐标（多数部件）b) `translate(1024 0) scale(-1 1)` 复用（睫毛）c) 同向复制（腮红斜线，两侧都画 "///" 方向）
3. **双层瞳孔**：`#244a83` 大椭圆 + `#163663` 半透明小椭圆叠加，比单色更有深度
4. **柔化滤镜复用**：`eyeGlow` 同时服务眼底反光和腮红
5. **遮挡即层次**：后腿后画 = 在前；耳根盖片 = 无描边补丁遮接缝
